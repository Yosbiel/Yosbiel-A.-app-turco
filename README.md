# Turco - Gestión de Turnos

Proyecto práctico para la asignatura Programación de Dispositivos Móviles.

## Tecnologías
- Flutter
- GoRouter
- ChangeNotifier (MVVM)

## Cómo ejecutar
1. Clonar el repositorio.
2. Ejecutar `flutter pub get` para instalar las dependencias.
3. Ejecutar `flutter run` en un emulador o dispositivo físico.

## Application ID
El application id es `com.yosbielalejandro.diazcala.turco`.

## Cómo generar el APK
Ejecutar el comando:
`flutter build apk --release`

El archivo APK se generará en `build/app/outputs/flutter-apk/app-release.apk`.
